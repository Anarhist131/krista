## 📖 О проекте

Криста — это лёгкий мессенджер для общения с друзьями, близкими и небольшими сообществами. Работает как PWA — устанавливается на домашний экран и работает как обычное приложение. Сообщения летают моментально через WebSocket, интерфейс минималистичный и приятный, без лишнего.

Проект **с открытым исходным кодом** — любой может форкнуть, доработать под себя и запустить свой инстанс. Никаких трекеров, аналитики и слежки.

## ✨ Возможности

### 💬 Общение
- **Личные диалоги** 1 на 1 по логину
- **Группы и каналы** с логином, приватностью и публикацией в каталоге
- **Реальное время** через WebSocket — сообщения приходят мгновенно
- **Ответы на сообщения** с переходом к оригиналу
- **Реакции на сообщения** (❤️ 🔥 👍 😂 😢 😡)
- **Упоминания** через `@логин`
- **Индикатор «печатает...»**
- **Экспорт переписки** в TXT-файл
- **Закреплённые сообщения** (для админов)
- **Управление администраторами** — назначение и снятие
- **Черновики** — не теряются при переключении чатов
- **Клик по ссылкам** — открываются в браузере

### 📰 Хабр
- **RSS-лента Хабра** прямо в приложении
- Фильтры: `Все` / `Лучшие за сутки` / `По хабрам`
- Кэш на сервере 20 минут — не дудосим Хабр
- Чтение статей внутри приложения
- Кнопка «Читать на Хабре», для перехода к полным статьям

### 🌐 Каталог
- **Публичные группы и каналы** в одном месте
- **Топ по подписчикам** — от первого к последнему
- Публикация собственного чата одним переключателем
- Быстрое вступление в один тап

### 🎨 Внешний вид
- **2 темы:** Тёмная и Светлая
- **8 акцентных цветов** из нежной пастельной палитры
- **5 наборов шрифтов** (Классика, Техно, Тёплый, Книжный, Моно)
- **Регулировка матовости** стекла (слайдер 0–40px)
- **Стеклянный интерфейс** с blur-эффектами
- **Скруглённые квадратные аватары** — единый стиль
- **Редактор набора эмодзи** — свой список для панели в чате
- **Эмодзи возле ника** с настраиваемым цветом

### 👤 Профиль и аккаунты
- **Аватар:** инициал имени или эмодзи + цвет фона
- **Ник** с настраиваемым цветом
- **Смена логина** (раз в 24 часа)
- **До 4 аккаунтов** с быстрым переключением
- **Счётчик аккаунтов и онлайна** в настройках

### 🔍 Поиск
- Единая модалка — ищет людей, группы и чаты
- История поиска с возможностью удаления

## 🛠 Стек

- **Backend:** Node.js, Express, `ws`, MongoDB Atlas
- **Frontend:** чистый HTML/CSS/JS без фреймворков
- **PWA:** Service Worker, манифест, установка на домашний экран
- **Шрифты:** Comfortaa, Inter, Unbounded, Manrope, Raleway, Nunito, Playfair Display, Open Sans, JetBrains Mono
- **Пакеты:** `bcrypt`, `jsonwebtoken`, `uuid`, `rss-parser`

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Anarhist131/krista.git
cd krista
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Настроить переменные окружения

Создай файл `.env` в корне:

```env
PORT=3000
JWT_SECRET=твоя_длинная_случайная_строка
MONGO_URI=mongodb+srv://user:pass@cluster.mongodb.net/?retryWrites=true&w=majority
DB_NAME=krista
```

### 4. Запустить

```bash
npm start
```

Открой `http://localhost:3000` — регистрируйся, придумывай логин, общайся.

## ☁️ Деплой на Render

1. Залей проект на GitHub
2. На Render → **New Web Service** → подключи репозиторий
3. Настройки:
   - **Environment:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. В **Environment Variables** добавь:
   - `JWT_SECRET` — длинная случайная строка
   - `MONGO_URI` — строка подключения к MongoDB Atlas
   - `DB_NAME` — `krista`
5. **Deploy**

Не забудь в MongoDB Atlas:
- Создать пользователя БД с правами `readWriteAnyDatabase`
- В **Network Access** разрешить IP `0.0.0.0/0` (иначе Render не подключится)
